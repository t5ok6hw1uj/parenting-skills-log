# 孕早期能吃花菜吗

> 更新时间：2026-09-15 (UTC+8)

**1孕早期能吃花菜吗**

　　花菜富含维生素K、蛋白质、脂肪、糖类、维生素A、C、B族维生素及钙、磷、铁等营养素。孕妇产前经常吃些花菜,可预防产后出血.及增加母乳中维生素K的含量。

　　花菜除了营养价值高之外,最大的优点是常吃可防治疾病。它能增强肝脏的解毒能力及提高机体的免疫力,预防感冒,防治坏血病等疾患。用花菜叶榨汁煮沸后加入蜂蜜制成糖浆,有止血止咳、消炎祛痰、润嗓开音之功效,更是预防新生儿颅内出血、皮下出血、上呼吸道感染的药膳。孕妇常吃花菜有益。

　　花菜的营养比一般蔬菜丰富。它含有蛋白质、脂肪、碳水化合物、食物纤维、维生素A、B、C、E、P、U和钙、磷、铁等矿物质。花菜质地细嫩，味甘鲜美，食后极易消化吸收，其嫩茎纤维，烹炒后柔嫩可口，适宜于中老年人、小孩和脾胃虚弱、消化功能不强者食用。尤其在暑热之际，口干渴、小便呈金黄色，大便硬实或不畅通时，用花菜30克煎汤，频频饮服，有清热解渴，利尿通便之功效。

**2孕妇吃菜花的做法**

　　1、菜花炒肉的做法

　　食材：菜花250克，猪瘦肉150克，油、盐和蚝油分别适量。

　　(1)菜花洗净，撕成小朵;肉切丝。

　　(2)热锅冷油下肉丝滑至变色。

　　(3)菜花大火快炒，断生后调入适量生抽蚝油，调入少量盐炒匀即可。

　　功效：猪肉提供人体生理活动必需的优质蛋白质、脂肪，具有滋阴润燥、益精补血的功效，适宜于气血不足，阴虚纳差者。菜花有补虚下乳，平肝利尿，消肿止血的功效。

　　2、干锅菜花的做法

　　食材：菜花250克，腊肉150克，豆瓣酱、豆豉、油、生抽、蒜片和盐分别适量。

　　做法：

　　(1)菜花洗净掰小块。

　　(2)烧一锅热水，水开后倒入菜花，捞出，沥干水分。

　　(3)腊肉用水煮半小时，煮好后，切小片待用。

　　(4)热锅里放少许油，放入切片的腊肉，小火慢慢地煸成出油后的焦黄色，放入豆瓣，小火慢慢煸出红油后，加入豆豉和蒜片，出香味后，倒入菜花，开大火，倒入少许生抽，快速翻炒，使汤汁收到很少后，加少许盐即可。

　　功效：菜花具有降低动物血清胆固醇作用，是预防高血脂和延缓机体衰老的佳蔬。

**3菜花的功效**

　　花菜的营养价值

　　菜花的营养比一般蔬菜丰富。它含有蛋白质、脂肪、碳水化合物、食物纤维、维生素A、B、C、E、P、U和钙、磷、铁等矿物质。菜花质地细嫩，味甘鲜美，食后极易消化吸收，其嫩茎纤维，烹炒后柔嫩可口，适宜于中老年人、小孩和脾胃虚弱、消化功能不强者食用。尤其在暑热之际，口干渴、小便呈金黄色，大便硬实或不畅通时，用菜花30克煎汤，频频饮服，有清热解渴，利尿通便之功效。

　　花菜的功效与作用

　　花菜不仅是营养丰富的蔬菜，更是一种保健蔬菜。在美国《时代》杂志推荐的十大健康食品中名列第四;美国公众利益科学中心把花椰菜列为十种超优食物之一。花菜能防癌抗癌，提高肝脏解毒能力、增强机体免疫功能、促进生长、维持牙齿及骨骼正常、保护视力、提高记忆力和维护血管韧性。

**4花菜对人体有哪些好处**

　　1. 抗癌防癌：花菜含有抗氧化防癌症的微量元素，长期食用可以减少乳腺癌、直肠癌及胃癌等癌症的发病几率。据美国癌症协会的报道，在众多的蔬菜水果中，菜花、大白菜的抗癌效果最好;

　　2. 清化血管：花菜是含有类黄酮最多的食物之一，类黄酮除了可以防止感染，还是最好的血管清理剂，能够阻止胆固醇氧化，防止血小板凝结成块，因而减少心脏病与中风的危险;

　　3. 丰富的维生素K：有些人的皮肤一旦受到小小的碰撞和伤害就会变得青一块紫一块的，这是因为体内缺乏维生素K的缘故，补充维生素K的最佳途径就是多吃花菜;

　　4. 解毒肝脏：多吃花菜还会使血管壁加强，不容易破裂。丰富的维生素C含量，使菜花可增强肝脏解毒能力，并能提高机体的免疫力，可防止感冒和坏血病的发生;

　　5. 维C使者：花菜的维生素C含量极高，不但有利于人的生长发育，更重要的是能提高人体免疫功能，促进肝脏解毒，增强人的体质，增加抗病能力，提高人体机体免疫功能。尤其是在防治胃癌、乳腺癌方面效果尤佳，研究表明，患胃癌时人体血清硒的水平明显下降，胃液中的维生素C的浓度也显著低于正常人，而菜花不但能给人补充一定量的硒和维生素C，同时也能供给丰富的胡萝卜素，起到阻止癌前病变细胞形成的作用，抑制癌肿生长;

　　6. 生物活性：据美国营养学家研究，花菜内还有多种吲哚衍生物，此化合物有降低人体内雌激素水平的作用，可预防乳腺癌的发生。此外，研究表明，菜花中提取的一种酶能预防癌症，这种物质叫萝卜子素，有提高致癌物解毒酶活性的作用;另外菜花中还含有二硫酚硫酮，可以降低形成黑色素的酶及阻止皮肤色素斑的形成，经常食用可滑润开胃，对肌肤有很好的美白效果。

**5食用花菜的注意事项**

　　1、花椰菜容易生菜虫，在生长的过程中，有些人为了减少菜虫对花椰菜的残害，会喷洒大量的农药，再加上花椰菜表面凹凸不平，更易积蓄农药残留，所以吃花椰菜前应先放盐水中浸泡5分钟，以去除残留农药和菜虫。

　　2、花椰菜在肠胃中分解后容易引起胀气。不过，如果在烹调花椰菜时加一些大蒜、胡椒、小茴香等辛辣调料，便可以大大减少胀气的不适，还有利于增进食欲，帮助消化。

　　3、花椰菜不耐烧煮，宜急火快炒，尽量选择短时间加热的方法，断生之后马上盛出，这样才能保持清香脆嫩的口感，使营养素与抗癌成分不致破坏和丢失。而且花椰菜切好之后不能久放，因为在室温空气中放置6小时后，其抗癌成分的损失率可达75%之多。

　　4、注意食材的搭配。花椰菜中含有少量导致甲状腺肿大的物质，经常食用者应注意补充碘，如加入碘盐或食用海藻等海味食物。另外，花椰菜不宜与猪肝和黄瓜同食。花椰菜纤维中的醛糖酸基容易与猪肝中的铁、锌等微量元素发生反应，因此两者同食会导致人体对这些元素的吸收大大降低;猪肝中的铜、铁元素还会使花椰菜中的维生素C氧化为脱氢抗坏血酸，失去原来的功效。
